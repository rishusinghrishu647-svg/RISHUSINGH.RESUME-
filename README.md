# Rishu Singh — Finance Portfolio

This is a static HTML portfolio website.

## Deploy with GitHub Pages
1. Create or open a GitHub repository.
2. Upload `index.html` to the repository's root folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.
6. Wait for deployment to finish. GitHub will show the published website URL in the Pages section.

No build tools or dependencies are required.
